# General instructions

* If a new source or text file is generated, please add `@Copyright {{year}} Syd Polk. All Rights Reserved`
* If you modify a source file without a copyright, please add the above notice.
* If you modify a source file with an existing notice, and the current year is different from the last year listed, add a comma and the current year, i.e., `@Copyright 2026 Syd Polk. All Rights Reserved` becomes `@Copyright 2026, 2027 Syd Polk. All Rights Reserved`. It's explcity ok to skip years, i.e., `2026, 2028`
